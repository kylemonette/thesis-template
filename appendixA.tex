\chapter{Supplementary Material}
\label{app:supplementary}

This appendix contains material that supports the main text but would
interrupt the flow of the argument if placed in the body of the thesis.
Typical appendix content includes:

\begin{itemize}
  \item Detailed mathematical derivations.
  \item Extended data tables.
  \item Pseudocode or source code listings.
  \item Instrument specifications or calibration data.
  \item Copies of survey instruments or protocols.
\end{itemize}

\section{Detailed Derivation}
\label{app:derivation}

Place extended derivations here.
For example, the derivation of Equation~\eqref{eq:metric} from first
principles, which would have been too long to include in
Chapter~\ref{ch:methods}.

\section{Additional Data Tables}
\label{app:tables}

Additional tables that did not fit in the main chapters can appear here.
Figures and tables in appendices are excluded from the List of Figures
and List of Tables by the class, as required by the Graduate School.
